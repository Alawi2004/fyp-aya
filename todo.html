In backend/src/app.js line 40: replace cors() with cors({ origin: ['http://localhost:5173', 'http://localhost:5174', 'https://your-production-domain.com'], credentials: true }). Currently any website on the internet can make cross-origin requests to your API.

SEC-08 High Security Frontend
Move auth token from localStorage to HttpOnly cookie to prevent XSS token theft
In apiClient.js, getToken() reads from localStorage — easily stolen via XSS. Change to use HttpOnly, Secure, SameSite=Strict cookies. The backend needs to set Set-Cookie on login responses. The refresh endpoint needs to accept the cookie. This is a significant refactor but critical for security.
✓
SEC-09 High Security Backend
Add rate limiting to register endpoint and all non-auth routes
Currently only auth login/refresh have rate limiting. Add: register (max 5/hour per IP), vehicle CRUD (max 100/min), all API routes general limiter (max 200/min). Use the existing rateLimiter.middleware.js pattern. Without this, the API is vulnerable to enumeration and resource exhaustion attacks.
✓
SEC-10 High Security Backend
Require TOTP re-confirmation to disable 2FA
In auth.controller.js, the disable2fa handler (line 456) only checks requireAuth — it doesn't verify the current TOTP code. An attacker who steals an access token can immediately disable 2FA. Add { totp_code } to the request body and verify with speakeasy before disabling.
✓
SEC-11 High Security Backend
Fix ADMIN_BASE_URL — currently points to local LAN IP 192.168.1.109:5173
In backend/.env: ADMIN_BASE_URL=http://192.168.1.109:5173. Password reset emails send links like http://192.168.1.109:5173?token=... which only work on the same local network. Change to the real public domain or https://localhost:5173 for dev. Users outside the network cannot reset their passwords.
✓
